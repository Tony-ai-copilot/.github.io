# Tony's Programming Portfolio

This is my AP Computer Science Final Portfolio Project. It showcases my programming projects, technical skills, and learning journey through the course.

## Portfolio Structure

- **Home Page** (`index.html`) - Introduction and welcome
- **About Me** (`about.html`) - My interests, hobbies, and technology passions
- **Projects** (`projects.html`) - At least 4 programming projects with descriptions and lessons learned
- **Resume** (`resume.html`) - Education, skills, activities, and experience
- **Reflection** (`reflection.html`) - 300+ word reflection on growth and learning

## Technologies Used

- HTML5
- CSS3
- Responsive Design
- GitHub Pages

## Getting Started

This portfolio is hosted on GitHub Pages. You can view it at: `https://tony-ai-copilot.github.io`

## How to Update

1. Clone this repository
2. Edit the HTML files with your projects and information
3. Update the CSS in `styles.css` for styling changes
4. Push changes to the `main` branch
5. Your changes will be live within a few minutes

## Customization Tips

- Replace placeholder project titles and descriptions with your actual projects
- Add GitHub links to your project repositories
- Update contact information in the footer
- Add screenshots or images of your projects
- Customize colors in `styles.css`

## Grading Rubric

This portfolio is evaluated on:

- **Organization & Design** - Professional, clean layout
- **Completeness** - All required sections included
- **Project Explanations** - Clear descriptions and technical details
- **Technical Quality** - Well-structured code and responsive design
- **Reflection & Professionalism** - Meaningful reflection and professional presentation
- **Creativity & Effort** - Unique design and thoughtful content
