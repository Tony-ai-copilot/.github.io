Description: This coding project, that was done in CMU CS Academy, is executed whenever there is specific user input within the text entry box. This project is solely built as a "fun" project, it isnt necessarily built for much of a purpose, besides being used as one of my personal projects for this portfolio.

Key Challenges:

  • Challenge 1: The arrow movement at the bottom of the screen was quite the obstacle to overcome. I struggled for a bit on all the numbers involved in making them continuously move up and down, and at such high speeds, or so the illusion of it going that fast

  • Lesson 1: I've learned that coding is a fundamental skill needed if im going to be pursuing a career that obviously would happen to involve such knowledge.
